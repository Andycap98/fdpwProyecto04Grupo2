
# Componentes del proyecto

En esta carpeta se desarrollarán los componentes
de React del simulador El Dado de la Suerte.

- Dado.jsx: muestra el dado y permite lanzarlo.
- FormularioJugador.jsx: registra nombre, apellido y edad.
- MensajeResultado.jsx: muestra el mensaje según el resultado.

Cada integrante desarrollará su componente
en su rama personal.
